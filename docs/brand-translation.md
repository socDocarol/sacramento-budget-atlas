# Brand translation

The controlling reference is the March 2013 City of Sacramento Graphic
Standards manual, last visibly reviewed in February 2014. The local PDF
SHA-256 is
`355E288F8BC54D60D74E6676AD56C0128D47BAB26A0A6768AD1582952C77AE82`.

## Identity

- Use the supplied `footer-icon.png` white reproduction artwork on the cobalt header and footer without
  recoloring, cropping, rearranging, distortion, or internal animation.
- Render the header signature at 110 CSS pixels wide on desktop and 84 CSS
  pixels on mobile as an explicit compact-shell exception. Render the footer
  signature at 210 CSS pixels wide on desktop and 184 CSS pixels on mobile;
  the footer remains above the manual's one-inch guidance.
- Preserve clear space around the signature of at least 16 CSS pixels.
- Keep the experimental Atlas name separate from the official signature.
- Do not use the City seal.

## Digital palette

- Cobalt: `#2A3B66`
- Slate: `#76AFDF`
- Feather gold: `#E9C791`
- River ink: `#10233F`
- Paper: `#F6F3EC`
- Mist: `#DDEBF2`
- Cypress: `#24645B`
- Coral warning: `#B95045`
- White: `#FFFFFF`

The first three colors are official identity anchors. The remaining colors
are application colors selected for contrast, hierarchy, and data
distinguishability. They are not new City identity standards.

## Typography

The demo does not bundle the licensed Gill Sans Pro Light or Garamond Premier
Pro Display Light Italic fonts. Inter is used for interface and financial
values. Georgia provides a limited editorial voice. The official signature is
never recreated with substitute type.
